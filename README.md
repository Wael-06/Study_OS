# Study OS

> A local-first study planner for turning learning goals into actual work.

Study OS is a personal learning and productivity system designed to help you organize what you want to learn, decide what to work on, and keep track of your progress.

It is built around a simple idea:

**Learning should be a process you can see, plan, execute, and review.**


## Getting started

### Requirements

* Node.js 22 or newer
* npm

### Install

```bash
npm install
```

### Start Study OS

```bash
npm run dev
```

Then open:

```text
http://127.0.0.1:5000
```

### Build for production

```bash
npm run build
```

Built because I needed a better way to learn.
